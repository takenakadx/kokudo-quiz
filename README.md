# kokudo-quiz

国道が日本のどこからどこまで続いているかを、地図上で指（マウス）でなぞって覚えるクイズアプリです。
ビルド不要の静的HTML/JS/CSSのみで動作し、`index.html` をブラウザで開くだけで利用できます。

公開URL（GitHub Pages）: https://takenakadx.github.io/kokudo-quiz/

- 地図表示には [Leaflet](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/copyright) のタイルを使用しています。実際の地図データを表示するため、**利用時はインターネット接続が必要です**（地図タイルとLeaflet本体をCDN経由で読み込みます）。
- 学習モード・クイズモードとも**1画面に収まる**ようにしてあり、操作ボタンまでスクロールする必要はありません。画面の高さが余った分は地図が受け取り、収まりきらない国道一覧や結果表示はそれぞれの内側でスクロールします。スマホを横向きにしたときは、地図を左・操作を右に置いた2カラムに切り替わります。
- **学習モード**：国道を選ぶと、実際のルートを地図上にアニメーション表示。起点・終点、通過する都道府県、総距離、トリビアといった補足情報も確認できます。地図は自由にpan/zoomできます。
- **クイズモード**：出題文には国道番号と難易度のみが表示され、起点・終点の都市名も地図上のマーカーも伏せられます。起点だと思う場所を自分の記憶だけを頼りに指（マウス）でなぞり始め、実際の経路をなぞって解答します。
  - **出題範囲（マップ）を選べます**：「一桁国道」「二桁国道」「三桁国道」のほか、「関東地方」「近畿地方」など通過する地方でも絞り込めます（1つの国道が複数の地方にまたがる場合は、その全部の地方マップに登場します）。難易度フィルターと組み合わせることもでき、組み合わせて対象が0問になった場合はマップの絞り込みを優先し、難易度は無視して出題します。選択中の設定でいま何問が対象かは、出題前のバナーに表示されます。
  - 出題は「山札」方式です。選んだ範囲の全問をシャッフルして順番に出し、山札を使い切ったらまた作り直すので、範囲を絞っていても一巡するまでは同じ問題を引きません。
  - **操作**：1本指ドラッグ（マウスは左ドラッグ）でなぞり、2本指（マウスは中ボタンドラッグ・ホイール）で地図をpan/zoomします。なぞっている途中で2本目の指が触れた場合は「地図を動かすつもりだった」と解釈して、その線は破棄されます。
  - **何回かに分けてなぞれます**。指を離しても採点されず、「採点する」を押すまで何本でも描き足せます。直前の1本だけ消す・全部消すこともできます。
  - 採点は、なぞった軌跡を「太さのあるペンで塗った帯」とみなし、実ルートがどれだけその帯に含まれるか（ルート網羅率）で行います。塗りつぶして得点を稼げないよう、なぞれる総距離は実ルート長の120%に制限されており、残量は画面上部のゲージで確認できます。
  - 「塗れた」と認めるのは、**道に沿ってなぞった**ぶんだけです。具体的には ①ペン幅の内側にあり、かつ ②なぞった向きが道の向きから45度以内、の両方を満たす部分だけを数えます。また帯の両端は平ら（丸めない）に扱います。こうしないと、少し指を動かすだけでペン幅ぶんの円が塗れてしまい、短いストロークを並べるだけで、ほとんどペンを使わずに広い範囲を網羅できてしまいます。逆向き（終点→起点）になぞるのは問題ありません。線と線の間の描いていない部分も塗ったことになりません。
  - 採点すると、正誤に関わらず**その国道の補足情報**（起点・終点、通過する都道府県、総距離、トリビア）が地図の上に重ねて表示されます（間違えたときこそ覚えてもらうため）。✕で閉じると地図の答え合わせができます。
  - ヒントを使うと都市名と起点・終点のマーカーが表示されますが、その問題は「正解」判定にはならず（最高でも「惜しい」）、表示スコアも半分になります。なぞっている最中にルートから外れると軌跡が赤く表示され、効果音（ミュート可）と共に正誤がフィードバックされます。
  - ペン幅（判定の許容範囲）とペン残量は、出題されている国道自身の画面上の長さに比例して決まります。長い国道ほど太く、短い国道ほど細くなり、拡大するとどちらも同じ倍率で大きくなるため、拡大しても有利にも不利にもなりません。ただし国道22号・43号のような短い国道は日本全体の縮尺では画面上数pxしかなく事実上なぞれないため、その場合は拡大を促すメッセージを表示します。
- 収録国道や成績、難易度フィルターの選択、効果音のON/OFFはすべて端末内（`localStorage`）にのみ保存され、外部サーバーへの送信は行いません（地図タイルの読み込みを除く）。

## 収録国道とルートデータ
現在35路線を収録しており、すべてのルート形状は[OpenStreetMap](https://www.openstreetmap.org/copyright)の実際の道路データから生成しています。収録国道の一覧・区間・補足情報は[国道収録仕様書](https://takenakadx.github.io/kokudo-quiz/spec/)にまとめています。

`highways-data.js` は `tools/gen_highways_data.py` が生成するため直接編集しません。アプリ本体（`index.html`）は `HIGHWAYS` 配列を読むだけなので、国道を増やしてもアプリのコード変更は不要です。

### 国道を追加・修正する手順
1. `data-raw/README.md` の手順で、Overpassからその国道の生データ（GeoJSON）を取得して `data-raw/◯◯.geojson` に置く
2. `tools/process_routes.py` の `CHECKPOINTS` に、その国道が通る主要都市の座標を**通る順に**追記する
3. `python3 tools/process_routes.py` を実行する（`tools/processed/◯◯.json` が生成され、品質指標が表示される）
4. `tools/gen_highways_data.py` の `META` に表示名・通過都道府県・難易度・豆知識を追記し、実行して `highways-data.js` を再生成する

### なぜ「経由都市」を人手で与えるのか
Overpassから取得できる生データは、その国道を構成する道路の実際の座標ではありますが、**順序も向きもバラバラな断片の集まり**です。単純に「起点から近い断片を順につなぐ」方式では、交差点や並走路で分岐を取り違えて経路が迷子になります。そこで各国道が通る主要都市を「経由地」として人手で与え、**経由地間の短い区間ごとに断片を並び替える**ことで、道を取り違えてもその区間内に影響が収まるようにしています（`tools/process_routes.py` の `CHECKPOINTS` と `walk_leg`）。経由地の座標は大まかでよく、実データ上の最も近い点に自動でスナップされます。

`process_routes.py` は各ルートについて次の品質指標を出力します。`maxjump` が大きい場合は、その付近で生データが欠けているか、経由地が実際の道から離れた場所を指しています。

| 指標 | 意味 |
| --- | --- |
| `len` | 復元されたルートの総距離（実際の国道の距離と比べて妥当か確認する） |
| `start_mm` / `end_mm` | 復元された経路の端点が、想定した起点・終点からどれだけ離れているか |
| `maxjump` | 経路上で連続する2点間の最大距離。大きいほど不自然な「飛び」がある |
| `leg mismatch` | 経由地に到達できなかった区間とその距離 |
| `cp snapped far` | 指定した経由地が実データから遠い（座標が違う道の上にある可能性） |
