# kokudo-quiz

国道が日本のどこからどこまで続いているかを、地図上で指（マウス）でなぞって覚えるクイズアプリです。
ビルド不要の静的HTML/JS/CSSのみで動作し、`index.html` をブラウザで開くだけで利用できます。

公開URL（GitHub Pages）: https://takenakadx.github.io/kokudo-quiz/

- 地図表示には [Leaflet](https://leafletjs.com/) + [OpenStreetMap](https://www.openstreetmap.org/copyright) のタイルを使用しています。実際の地図データを表示するため、**利用時はインターネット接続が必要です**（地図タイルとLeaflet本体をCDN経由で読み込みます）。
- **学習モード**：国道を選ぶと、実際のルートを地図上にアニメーション表示。通過する都道府県やトリビアも確認できます。地図は自由にpan/zoomできます。
- **クイズモード**：出題文には国道番号と難易度のみが表示され、起点・終点の都市名は伏せられます（地図上の始点マーカーだけが手がかり）。そこから指（マウス）で実際の経路をなぞって解答します。なぞった軌跡を「太さのあるペンで塗った帯」とみなし、実ルートがどれだけその帯に含まれるか（ルート網羅率）で採点します。塗りつぶして得点を稼げないよう、なぞれる総距離は実ルート長の120%に制限されており、残量は画面上部のゲージで確認できます。ヒントを使うと都市名と終点が表示されますが、その問題は「正解」判定にはならず（最高でも「惜しい」）、表示スコアも半分になります。なぞっている最中にルートから外れると軌跡が赤く表示され、効果音（ミュート可）と共に正誤がフィードバックされます。地図右上の「🗺️ 地図を動かす」ボタンでpan/zoomモードに切り替えられます（なぞる操作と1本指ドラッグが衝突するため、モードを分けています）。次の問題に進むと表示は自動的に日本全体・なぞるモードにリセットされます。
- 収録国道や成績、難易度フィルターの選択、効果音のON/OFFはすべて端末内（`localStorage`）にのみ保存され、外部サーバーへの送信は行いません（地図タイルの読み込みを除く）。

## 国道データの追加方法
`highways-data.js` の `HIGHWAYS` 配列にオブジェクトを1つ追加するだけで、新しい国道をアプリに追加できます（アプリ本体のコード変更は不要です）。現在は主要な国道12路線を収録していますが、今後のバージョンアップで追加していく想定の設計になっています。

```js
{
  id: 999,
  number: "国道◯号",
  startLabel: "起点の都市名",
  endLabel: "終点の都市名",
  prefectures: ["通過する都道府県", "..."],
  difficulty: 1, // 1(易) 〜 3(難)
  fact: "学習モードで表示する豆知識",
  waypoints: [
    [緯度, 経度, "地名"],
    // ... 経由都市を3〜8個程度
  ]
}
```

なお、ルートは実際の道路線形そのものではなく、主要都市を結んだ学習用の簡略ルートです。
